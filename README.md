# Interactive Robot Design Lab website

Static website of the Interactive Robot Design (IRoD) Lab, VinUniversity.

## Updating research projects (no code)
Edit projects in **Pages CMS** (https://app.pagescms.org). Sign in with GitHub, install the app on this repository, then open **Dự án nghiên cứu / Research projects**.

Every save commits a JSON file to `data/projects/`. The GitHub Action `.github/workflows/build.yml` then regenerates the pages and publishes them to GitHub Pages. The fields are described in `data/README.md`.

## What is where
- **Home** (`index.html`, `site.css`, `site.js`): two parts.
  - The self-moving balancing arm. It sweeps on its own; a visitor can drag it and let go.
  - The research list. It is generated between the `research:start` / `research:end` markers.
- **Subpages** (`content/…`): generated by `tools/gen.py` from `data/`, styled by `pages.css` / `pages.js`.
- **Themes and languages**: light/dark and English/Vietnamese switches on every page (`ui.js`). Vietnamese text for fixed content is in `tools/vi.json`.
- **Scroll engine**: `scrollcraft.js` / `scrollcraft.css`.
- **QA scripts**: Playwright scripts in `lab/*.mjs`.

## Local
```
python tools/gen.py          # regenerate pages from data/
python -m http.server 4500   # preview at http://localhost:4500
```
