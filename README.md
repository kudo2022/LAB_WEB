# Interactive Robot Design Lab website

Static website of the Interactive Robot Design (IRoD) Lab, VinUniversity. No build step: open `index.html` through any static server.

- Light / dark theme and English / Vietnamese, switched from the top bar and remembered per visitor (`ui.js`).
- Homepage: `index.html`, `site.css`, `site.js` (interactive balancing arm). Scroll engine: `scrollcraft.js` / `scrollcraft.css`.
- Subpages (`content/…`) are generated by `tools/gen.py` with `pages.css` / `pages.js`. Vietnamese text for long content lives in `tools/vi.json` (key = English).
- Regenerate: `python -I tools/gen.py <old-site-dump-folder> <cv.txt>` (source dumps are not stored in this repo).
- Local preview: `npx serve .` or `python -m http.server 4500`.
- QA scripts (Playwright): `lab/*.mjs`.
